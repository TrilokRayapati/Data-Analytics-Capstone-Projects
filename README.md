# Data Analytics Capstone Projects

A collection of end-to-end Data Analytics projects demonstrating data engineering, data analysis, machine learning, financial analytics, and business intelligence.

## Projects

### 1. Enterprise Business Intelligence Suite
**Objective:** Build an integrated business intelligence reporting solution for a multi-region company.

**Key Areas:**
- Sales, finance, HR, and supply chain analytics
- Data cleaning and transformation
- Star schema data modeling
- Business intelligence dashboards
- DAX measures and KPI reporting

**Technology Stack:** SQL, Power BI, DAX, Power Query, Excel, ETL, Data Modeling

[View Project](./DA-01_Enterprise_Business_Intelligence_Suite/)

### 2. Financial Analytics and Risk Reporting System
**Objective:** Develop a financial analytics solution for loan analysis, default prediction, and risk reporting.

**Key Areas:**
- Financial data analysis and validation
- SQL-based financial reporting
- Loan default prediction using machine learning
- Feature engineering and model evaluation
- Power BI financial dashboards

**Technology Stack:** Python, Pandas, NumPy, Scikit-learn, SQL, PostgreSQL, Power BI, DAX, Excel

[View Project](./DA-02_Financial_Analytics_and_Risk_Reporting_System/)
